# 5-minute pitch outline
1. Problem (30s): fast charging damages batteries; drivers want both.
2. Idea (45s): adaptive controller that picks the safest fast current every second.
3. How it works (60s): sense, estimate SOC, decide, act. One diagram.
4. Results (90s): comparison graph + table (charge time, peak temp, stress).
5. Live demo (45s): warm the sensor, current drops. Turn the pot, current tapers.
6. Impact and next steps (30s): longer battery life, lower cost, real-cell testing, BMS integration.
Backup: short video of the demo and the result graphs.
